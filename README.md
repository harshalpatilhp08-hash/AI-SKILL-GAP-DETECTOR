## 📌 Overview

The **AI Skill Gap Detector** is an intelligent career benchmarking and roadmap generation platform designed specifically for undergraduate engineering students and early-career developers. 

Campus curricula often struggle to match the fast-evolving demands of top tech employers. This platform bridges that divide by analyzing students' coursework, hands-on projects, and technical skills against real-world industry benchmarks, pinpointing critical competency blindspots and synthesizing step-by-step personalized sprint roadmaps.

---

## ✨ Key Features

- **⚡ Multi-Step Assessment Wizard**: Intuitive step-by-step profiling capturing academic major, technical proficiencies, portfolio projects, and target industry roles.
- **📊 Real-Time Skill Gap Visualization**: Interactive radar & comparative competency charts powered by Chart.js comparing current skill levels against target benchmark expectations.
- **🧠 Interactive Diagnostic Skill Quizzes**: Tailored question banks testing practical knowledge across multiple engineering specializations (Full Stack, Data Science, AI/ML, DevOps, Cloud).
- **🗺️ Personalized Sprint Roadmaps**: Automated generation of week-by-week actionable milestones, recommended learning resources, and capstone project ideas to eliminate identified skill gaps.
- **🎨 Design Thinking Architecture**: Built following a user-centric framework (Empathize, Define, Ideate, Prototype, Test).
- **🚀 One-Click Sample Profile Demo**: Instant pre-filled engineering student profiles for lightning-fast demonstration.

## 🚀 Quick Start (Local Setup)

Because the project is built using pure, standards-compliant web technologies, it requires **zero installation or build steps**:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/harshalpatilhp08-hash/AI-SKILL-GAP-DETECTOR.git
   cd AI-SKILL-GAP-DETECTOR
   ```

2. **Run in any browser**:
   - Simply double-click `index.html` to open directly in Chrome, Firefox, Safari, or Edge.
   - Or serve with any lightweight static HTTP server:
     ```bash
     # Using Python
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.
